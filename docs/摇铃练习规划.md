# 摇铃练习（读牌 / 防点炮）规划

> 目标：在现有拆搭训练器里加一个「对手」，他敲了以后，你根据他的牌河判断哪些牌危险、哪些能打，并立刻知道自己的选择值多少分。
>
> 核心原则：**判定用公式，读牌用概率；AI 只负责把数字讲成人话。**

---

## 1. 目标与非目标

### 要做

- 一个会打牌的 AI 对手：随机发牌 → 按最优出张打完整条路径 → 听牌后敲。
- 他敲之后，用本地算法反推他的听牌范围，给出**每张牌的点炮概率**。
- 练习循环：你出牌 → 结算「这张的放炮概率 / 最优替代是哪张」→ 累积得分。
- 可校准：跑批量模拟，报出命中率与校准误差，而不是「感觉挺准」。

### 不做（这一版）

- 三家全桌、碰/杠、吃、点炮结算、番数计分。
- 心理学、场况（谁领先）、对手风格建模。
- 任何依赖云端大模型算概率的部分（AI 只解释，不判断）。

## 2. 三个模块

### 2.1 对手模拟器（opponent.mjs）

```js
simulateRound(seed) -> {
  hand,            // 他的手牌（13 张）
  wall,            // 剩余牌墙
  path: [          // 每一手：摸到什么、打什么、当时向听
    { draw, discard, shanten, ukeire, tenpai: bool },
    ...
  ],
  knockAt,         // 他敲在第几手（tenpai 第一次成立）
  frozenHand,      // 敲时的 13 张（之后不变）
  waits,           // 敲时的听牌与枚数
}
```

策略（与判定器同源，保证自洽）：

1. 向听最小；
2. 同向听取进张最多；
3. 仍相同取孤张度高的、再取边张（复用 `analyzeHand` 的既有排序）。

**关键**：整条路径由这套确定性策略生成，所以「他为什么会打这张」永远是可解释的——这既是数据来源，也是将来解释文案的依据。

### 2.2 推断器（read.mjs）

输入：他的牌河（弃牌序列）、全体可见牌（自己手牌 + 四家牌河 + 副露）。
输出：`{ p: Map<tile, 概率>, survivors, samples }`。

```
枚举：从剩余牌池随机凑一手和牌（4 面子 + 1 将），抽掉一张 → 13 张听牌手 H
权重：w = Π_{t∈waits(H), t 他打过} penalty(位置)
          × Π_{t∈H, t 他打过} holdPenalty^(H[t])
P(t|D) = Σ_H w · 1[t ∈ waits(H)] / Σ_H w
```

- **硬约束**：每张牌不超过 `4 − 可见枚数`（牌池直接扣掉）。
- **软权重**：他打过的牌如果正好是这手牌的听张，说明这手不太可能是他的；越靠后的弃牌惩罚越重（最近 4 张 `0.08`，更早 `0.35`）。他还留着「早就打掉过」的牌也扣分（`0.35^n` / `0.75^n`）。
- **为什么不再逐手模拟路径**：硬匹配「候选手牌逐手都持有他打出的那张」实测 1000 个样本只剩 4~5 个存活（单巡通过率约 40%，8 手后必然塌到 0）。弃牌真正提供的信息是「他不要什么」，直接拿它当约束更稳、也快得多。
- **采样量直接决定精度**（实测）：120 样本 top-3 只有 10~20%（等于噪声）；1200 样本 63%（8 局小样本）；500 样本 / 27 局 = 44%。每样本约 2.3ms，500 样本 ≈ 1.2s。

#### M0 实测（`node test/readcalib.mjs 40 500 1.2`，27 手有效）

| 指标 | 数值 | 参照 |
|---|---|---|
| top-3 命中 | **44%** | 随机 ≈ 30%（`1 − C(24,3)/C(27,3)`） |
| top-5 命中 | **56%** | 随机 ≈ 43% |
| Brier | **0.0559** | 全 0 基线 0.0617 |
| 耗时 | 1.20s / 手（500 样本） | 目标 < 300ms → 见下方 |

踩过的坑（写下来免得重犯）：

1. 硬路径匹配 → 样本塌方（上面已说）。
2. 校准时把**他的起手牌当成「我的手牌」**塞进可见牌 → 他的听张被从牌池里扣掉，排名直接反相关（top-3 掉到 10%）。可见牌必须是独立发牌的 13 张。
3. 样本数不足时，排名就是噪声——别用 100 样本的结果下结论。


### 2.3 练习器（drill 层）

- 他敲 → 冻结他的手牌 → 面板出现「读牌」区。
- 你的手牌上叠加危险色（红/黄/灰），悬停显示该牌的 `p` 与理由。
- 你出牌后结算：

```
你的 P = danger(你打的牌)
最优 P = min over 可打牌 danger(t)
得分   = 10 × (1 − (P − 最优P) / 最优P)     // 打了最安全那张 = 10 分
放炮   = P > 阈值 且  随机命中（模拟他是否真和）
```

- 复盘：显示「他把哪张打了、留了什么、真正听什么」，并对照你的判断。

## 4. 评分口径（重要）

这一版**不判对错**，只给 EV：

- 你打出的牌：`p`（点炮概率）。
- 面板同时给出「最安全的那张」是什么、`p` 是多少。
- 得分按 `p` 的相对差算，避免「反正都会点炮」的挫败感。

这样它和现在的拆搭训练是同一套哲学：**规则算得分，AI 讲原因**。

### 4.1 口径变更：从「对错」改成「按牌河排名」（2026-11-12）

初版（M1）实际上跳过了 M2，直接拿真手牌（`sim.waits`）判对错，等于给玩家开透视；题袋还按真听张凑成一半危险一半安全，把答案写进了题面。

实测两个后果：`visible` 里算进了「我手上那 12 张」，而它们本来就是从听张里挑的 → 他的听张牌池被抽干，模型给真听张的排名反而最安全（P(rank≤3 | 真听张) = 0%，安全牌 3.4%）。

现在改成：

- **发牌**：我的 13 张从「他没摸到过的牌」里随机发，不按答案凑；真听张约占 8%。
- **判分**：`read.mjs` 推断出的 27 种牌危险排名，前 5 名算「危险」；选择和排名一致算对，正好卡在第 5/6 名的压线题不计分。
- **真值**：只决定「打出去会不会被和」，只在点炮或整局结束时揭晓。
- **校准数据**（独立发牌，按张）：top-5 真听张 11.1% vs 安全牌 5.5%（2.0 倍 lift）；top-3 4.9% vs 2.5%。注意这和 §2.2 的 44% 不是一回事——那个是「每局至少一张进前三」的按局口径。
- 旧的「无线索题」（`readable:false`）取消：每张牌都有概率，读不出线索时概率自然拉平，这就是它该有的样子。

§4 里「按 EV 打分」仍是 M3 的目标形态，尚未实现；当前是 top-5 二元判定 + 压线题豁免。

## 5. 校准（决定它是不是「公式」）

需要三个可复现的指标，写进测试：

1. **top-3 命中率**：真实听牌中至少一张落在我们前三危险牌里的比例。
2. **Brier 分数**：`mean((p − outcome)²)`，越小越好。
3. **过自信检查**：把预测概率分桶（0–10%、10–20%…），对比桶内实际发生率；偏差 > 10 个百分点就要调 β。

达不到就说明模型不行，**不许上「读牌」按钮**。

## 6. 风险与预案

| 风险 | 预案 |
|---|---|
| 硬匹配样本塌方（已实测） | 改软权重；采样量 500 起，必要时降到 300 但要接受噪声 |
| 敲麻没有振听，现物不是 0% | 表里给现物 3–5% 的小概率，不写「安全」 |
| 碰/杠没做，推断会偏 | v1 明确「门清局」；UI 上标注，别假装覆盖全部 |
| 人不会永远按最优打 | β 调到能容忍 1–2 手「次优」弃牌；或用「路线权重」单独处理染手 |
| 推断慢 | 采样在 Web Worker 里跑；或把候选池限制在「与敲的手数相容」的子集 |
| 玩家学的是错的东西 | 每次结算都展示真值；错题本强制复盘 |

## 8. 待拍板

1. **对手数量**：v1 只做 1 家（快、准、够练），还是直接 3 家（贵 3 倍，且要处理「谁在听」）？
2. **要不要碰**：v1 门清能覆盖大部分读牌，但敲麻的碰很常见；加碰要多写碰的推断（他碰了什么 = 少了什么）。
3. **练习形态**：接在现有牌局里（他敲 → 你接着打），还是单独一个「读牌练习」模式（给你一个残局，只问「这张危险吗」）？
