# 用 `www.你的域名.com` 打开

现在站点在 `https://hide0ngrass.github.io/qiaoma_trainer/`。换成 `https://www.example.com` 只需要两件事：**买一个域名** + **把域名指过去**。

站点本身不用改一行代码（`site/` 里的资源全是相对路径），所以下面两条路都只是「域名 → 托管」的配置。

---

## 先买域名

| 渠道 | 价格（首年） | 备注 |
| --- | --- | --- |
| 阿里云 / 腾讯云 | `.com` 约 ¥55–80/年，`.top` 首年 ¥9 | 国内平台，实名认证必须 |
| Cloudflare Registrar | `.com` 约 $10/年（成本价） | 只支持转入，先在别处注册 |
| Namecheap / Porkbun | `.com` 约 $10–12/年 | 支持支付宝的不多 |

买完记得做**实名认证**（国内注册商强制），否则域名会被暂停解析。

---

## 路线 A：继续用 GitHub Pages（免费，最快，10 分钟）

适合：不想维护服务器，能接受国内访问速度一般。

**1. 在 DNS 里加记录**

| 类型 | 主机记录 | 值 | TTL |
| --- | --- | --- | --- |
| CNAME | `www` | `hide0ngrass.github.io` | 600 |

（用阿里云/腾讯云 DNS 就填在「解析设置」里；用 Cloudflare 的话把橙色云朵关掉，选 **DNS only**，否则和 Pages 的 HTTPS 会打架。）

**2. 告诉 GitHub 这个域名**

仓库 → Settings → Pages → **Custom domain** 填 `www.example.com` → Save。
它会在仓库里生成一个 `CNAME` 文件（内容就是这行域名）。等 DNS 生效（几分钟到几小时），勾上 **Enforce HTTPS**。

**3. 让根域也跳过来（可选）**

`example.com`（不带 www）不能填 CNAME，要加 4 条 A 记录指向 GitHub：

```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

再在 Pages 的设置里把 `example.com` 也填进 Custom domain（GitHub 会自动 301 跳到 www，或反过来，看你哪个当主域）。

**注意**：`github.io` 在部分网络环境下会被干扰，如果主要给国内朋友用，见路线 B。

---

## 路线 B：Cloudflare Pages（免费 + 全球 CDN，同样不用服务器）

适合：想要更稳的访问、更快的国内速度，又不想备案。

1. Cloudflare 控制台 → Workers & Pages → Create → Pages → **Connect to Git** → 选 `qiaoma_trainer`
2. 构建设置：
   - Build command: `node tools/build-static.mjs`
   - Build output directory: `site`
   - Node 版本：`22`（环境变量加一条 `NODE_VERSION=22`）
3. 部署完 → Custom domains → 填 `www.example.com` → Cloudflare 自动加 CNAME 并签好证书
4. 域名如果也在 Cloudflare 托管，这一步是点一下就完事

这套配置和仓库里的 GitHub Actions 互不冲突：一个发布到 `github.io`，一个发布到你的域名。

---

## 路线 C：国内服务器 + 备案（www 最「正规」，但要等）

适合：要正式对外、要求国内访问快、能接受备案。

1. 买域名（阿里云/腾讯云）
2. 买一台轻量服务器（2 核 2G 起，¥60–100/月），**大陆节点必须备案**
3. 备案：在云厂商的备案系统提交，个人备案通常 5–20 个工作日，期间域名不能对外提供网站服务
4. 备案通过后：`A` 记录 `www` → 服务器公网 IP，Nginx 反代到 Node 进程，`certbot` 签证书

具体命令见 [`部署.md`](部署.md) 的方案 B。这套方案的好处是 AI 讲解可以统一配 key（访客不用自己填），代价是服务器费 + 备案时间 + 你要维护它。

---

## 怎么选

| 你想要的 | 选 |
| --- | --- |
| 今天就生效、零成本 | **A**（GitHub Pages + CNAME） |
| 稳一点、快一点、还是零成本 | **B**（Cloudflare Pages） |
| 国内访问最快、可统一配 key | **C**（备案 + 服务器） |

三条路都支持 **www 主域 + 根域 301 跳转**，对访客来说就是「一个正常的网站」。

---

## 常见坑

- **橙色云朵**：Cloudflare 代理开着 + GitHub Pages，会出现「重定向次数过多」。改 DNS only。
- **根域填 CNAME**：DNS 规范不允许（部分厂商用 ALIAS/ANAME 兼容），老老实实用 A 记录。
- **证书还没签就开 Enforce HTTPS**：页面会打不开，等 Pages 显示证书已签发再勾。
- **备案前解析到大陆 IP**：会被拦截，先备案再解析。
- **`www` 和根域只配一个**：两个都配但内容不一致，搜索引擎会当成重复站点；选一个当主域，另一个 301。
