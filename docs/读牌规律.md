# 读牌规律（实测版）

> 数据来源：本仓库的对手模拟器 `opponent.mjs`。它用和判定器同一套「最优出张」策略打到听牌就敲，所以**他敲牌那一刻的真实听张是已知的**——可以拿它给每条读牌直觉打分。
>
> 复现：`node test/rules.mjs 600`（411 局有效、11097 张牌面；他平均听 1.64 张 / 27 种）

## 基线

随机一张牌是听张的概率 = **6.07%**。下面所有倍数都以它为 1×。

## 一、单张特征（最强 → 最弱）

| 特征 | 是听张的概率 | 相对基线 | 样本 |
|---|---|---|---|
| 已见 4 张（死牌） | 0.0% | 0.00× | 28 |
| **現物**（他自己打过这张） | **0.6%** | 0.11× | 2931 |
| 已见 3 张（壁） | 1.9% | 0.31× | 322 |
| 幺九（1 / 9） | 4.0% | 0.65× | 2466 |
| 筋（±3 那张他打过） | 6.9% | 1.14× | 2639 |
| 他打得最多的那门 | 6.4% | 1.05× | 1679 |
| 中张（4-6） | 7.8% | 1.28× | 3699 |
| 无任何标记的牌 | 9.4% | 1.55× | 4982 |
| **他打得最少的那门** | **10.6%** | 1.75× | 2498 |

## 二、组合（叠乘效果）

| 组合 | 概率 | 相对基线 | 样本 |
|---|---|---|---|
| 中张 + 少打门 | **11.7%** | 1.93× | 920 |
| 非中张 + 少打门 | 9.9% | 1.64× | 1578 |
| 中张 + 非少打门 | 8.8% | 1.45× | 1965 |
| 非中张 + 非少打门 | 6.8% | 1.12× | 3158 |
| 幺九 + 少打门 | 7.9% | 1.29× | 458 |
| 幺九 + 非少打门 | 6.3% | 1.03× | 864 |

## 三、他「怎么打」的这张牌（邻居距离）

手切 = 从手里挑出来打；摸切 = 摸到什么打什么。

| 阶段 | 打法 | ±1 | ±2 |
|---|---|---|---|
| 前 3 手 | 手切 | **3.6%**（0.60×） | 4.8%（0.79×） |
| 前 3 手 | 摸切 | 6.2%（1.02×） | 3.7%（0.60×） |
| 中段 | 手切 | 5.3%（0.88×） | 6.1%（1.01×） |
| 中段 | 摸切 | 2.6%（0.43×） | 5.3%（0.87×） |
| 后期（8 手后） | 手切 | **10.0%**（1.65×） | 10.2%（1.68×） |
| 后期（8 手后） | 摸切 | **2.6%**（0.42×） | 4.4%（0.72×） |

## 四、可以拿来用的规律（按优先级）

1. **死牌 / 現物 → 先打**。0–0.6%，这是唯一接近「绝对安全」的信号。注意敲麻**没有振听**，現物不是 0%——但实测只有 0.6%。
2. **已见 3 张的牌 → 近似安全**（1.9%）。四张里三张在你或他牌河里，他只有最后一张。
3. **他打得最少的那门，整门抬高警戒**（10.6%，1.75×）。这一门的中张 4-6 最危险（11.7%，1.93×）。
4. **中张比幺九危险**：4-6 是 7.8%，1/9 只有 4.0%。手上要出中张时,先找同门的安全牌替换。
5. **后期（8 手后）看他怎么打的**：手切那张的邻居 ±1 危险（10.0%，1.65×）——他刚决定拆哪一组，拆掉那张旁边通常就是他留着的组；摸切那张的邻居反而很安全（2.6%）。
6. **早期（前 3 手）手切周围的牌很安全**（3.6%）：早期打的基本是孤张,周围没人要。

## 五、三个常见误区

| 直觉 | 实测 | 结论 |
|---|---|---|
| 「他拆了万子，所以万子安全」 | 多打那门 6.4%（1.05×） | **只是回到基线，不是变安全**；危险集中在少打那门 |
| 「筋牌安全」 | 6.9%（1.14×） | **几乎无效**。这版 108 张、无字牌、无吃碰，日麻的筋逻辑前提不成立 |
| 「后期摸切周围危险」 | 2.6%（0.42×） | **反了**。摸切 = 这张刚从墙上摸来、手里本来没有它，它周围多半也没有 |

## 六、局限

- 只有一个对手、一种策略（最优出张）、没有吃碰杠、108 张无字牌；真人对手的「手切/摸切」信息量会更强（他们会犹豫、会留安牌）。
- 「邻居」样本每格约 300–1700，±1 个百分点级别的差异不要当真；上表只保留 1.5× 以上的差异。
- 这些概率是**边际**的：真打牌时还要叠加「他第几手敲」「他已经副露/成型几组」这类信息。
